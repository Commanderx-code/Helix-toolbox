# Triage labels

The skills name five triage roles. Each is a label of the same name in this
repository's issues.

| Role and label    | Meaning                                       |
| ----------------- | --------------------------------------------- |
| `needs-triage`    | The maintainer needs to evaluate this issue   |
| `needs-info`      | Waiting on the reporter for more information  |
| `ready-for-agent` | Fully specified, ready for an agent to take   |
| `ready-for-human` | Needs a person to implement                   |
| `wontfix`         | Will not be worked on                         |
