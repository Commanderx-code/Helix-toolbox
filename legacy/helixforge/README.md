# helixforge

HelixForge is now **Helix Toolbox**:

```sh
cargo install --locked helix-toolbox
```

It installs `helix-toolbox` and its short name `htb`. Your settings,
profiles and history carry over. This version of `helixforge` only says so;
the versions before it are unchanged. See
[the repository](https://github.com/Commanderx-code/Helix-toolbox).
